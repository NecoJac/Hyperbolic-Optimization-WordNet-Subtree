# Riemannian Optimizers for Hyperbolic WordNet Subtree Classification

This repository contains the code, data, results, and report for the project
**Riemannian Optimizers for Hyperbolic WordNet Subtree Classification**.

The project studies whether Riemannian optimizers improve convergence and generalization when training a Poincare-hyperplane hyperbolic multinomial logistic regression classifier on WordNet subtree classification. The implementation is in Python with PyTorch and Geoopt.

The final report is included as:

```text
Riemannian_Optimizers_for_Hyperbolic_WordNet_Subtree_Classification.pdf
```

## Installation

Create a Python environment and install dependencies:

```bash
conda create -n hypopt python=3.10 -y
conda activate hypopt
pip install -r requirements.txt
```

Core dependencies are PyTorch, NumPy, pandas, scikit-learn, NetworkX, Matplotlib, PyYAML, tqdm, NLTK, and Geoopt.

## Data

The final experiments use real WordNet noun data and independently trained Poincare embeddings for each dimension:

```text
data/processed/wordnet_edges.csv
data/embeddings/wordnet_embeddings_d2.csv
data/embeddings/wordnet_embeddings_d3.csv
data/embeddings/wordnet_embeddings_d5.csv
data/embeddings/wordnet_embeddings_d10.csv
```

Nodes are WordNet synsets such as `mammal.n.01`. The four evaluated subtree roots are:

```text
ANIMAL.N.01, MAMMAL.N.01, GROUP.N.01, WORKER.N.01
```

For each subtree, positive examples are the root and all descendants. Negative examples are all remaining WordNet noun synsets. The `subtree_balanced` split separately applies an 80/20 split to positive and negative nodes.

## Models and Optimizers

The experiment compares three classifier families:

- `euclidean_lr`: logistic regression directly on Poincare coordinates.
- `logmap_lr`: logistic regression after mapping points to the tangent space at the origin.
- `hyperbolic_mlr`: two-class Poincare-hyperplane hyperbolic MLR.

The final configuration evaluates eight model/optimizer settings:

```text
euclidean_lr + adam
euclidean_lr + sgd
logmap_lr + adam
logmap_lr + sgd
hyperbolic_mlr + projected_sgd
hyperbolic_mlr + projected_adam
hyperbolic_mlr + rsgd
hyperbolic_mlr + radam
```

Projected optimizers use ordinary PyTorch updates followed by projection of Poincare-ball parameters. Riemannian optimizers use Geoopt's manifold-aware `RiemannianSGD` and `RiemannianAdam`.

## Reproducing the Experiments

### Quick Smoke Test

This verifies that the installation, data loader, models, training loop, aggregation, and plotting all work:

```bash
conda activate hypopt
python run.py --config configs/small_experiment.yaml
```

or equivalently:

```bash
scripts/run_local.sh configs/small_experiment.yaml
```

### Full Experiment

The full experiment reproduces the report tables and plots from scratch:

```bash
conda activate hypopt
python run.py --config configs/full_experiment.yaml
```

This runs:

```text
4 subtrees * 4 dimensions * 3 seeds * 8 settings = 384 runs
```

Expected outputs:

```text
results_wordnet_dims/logs/                  # per-run CSV logs
results_wordnet_dims/checkpoints/           # model checkpoints for plots
results_wordnet_dims/tables/main_results.csv
results_wordnet_dims/tables/optimizer_stability.csv
results_wordnet_dims/tables/main_results_latex.txt
results_wordnet_dims/figures/*.png
```

The full experiment can take several hours on CPU. On a RunAI cluster, split the four subtrees into separate jobs:

```bash
INSTALL_DEPS=0 scripts/run_full_split.sh
```

After all split jobs finish, aggregate and regenerate plots:

```bash
CONFIG=configs/full_experiment.yaml INSTALL_DEPS=0 scripts/plot_all.sh
```

For local aggregation from existing logs/checkpoints:

```bash
conda activate hypopt
python run.py --config configs/full_experiment.yaml --finalize-only
```

## Optional: Re-training Poincare Embeddings

The original Poincare embedding trainer is not vendored in this repository. To reproduce the embedding-training stage, clone the external implementation next to the project code:

```bash
git clone https://github.com/facebookresearch/poincare-embeddings.git poincare-embeddings
```

Then use the provided wrappers:

```bash
# Train D=2,3,5,10 embeddings on RunAI.
DIMS="2 3 5 10" FRESH=0 CONVERT_AFTER=0 scripts/runai_train_poincare_dims.sh

# Convert best checkpoints to the CSV files used by this project.
DIMS="2 3 5 10" CHECKPOINT_SUFFIX=".bin.best" scripts/convert_poincare_dims.sh
```

The external repo and generated `.bin` checkpoints are ignored by Git. Commit only the converted CSV files under `data/` if they are regenerated.

## Result Summary

The final aggregated table is `results_wordnet_dims/tables/main_results.csv`. The main result is that H-MLR with Riemannian Adam is the strongest overall setting:

| Setting | Mean F1 | Wins |
| --- | ---: | ---: |
| H-MLR + RAdam | 0.90 | 7 |
| H-MLR + Proj. Adam | 0.70 | 4 |
| H-MLR + RSGD | 0.68 | 1 |
| H-MLR + Proj. SGD | 0.56 | 3 |

The report discusses the full subtree-by-dimension results, optimizer stability, projection counts, runtime, and qualitative 2D trajectory/boundary plots.

## Code Notes

- `src/poincare_ops.py` contains the Poincare-ball operations used by the models.
- `src/models.py` implements Euclidean LR, log-map LR, and Poincare-hyperplane H-MLR.
- `src/optimizers.py` wraps projected Euclidean optimizers and Geoopt Riemannian optimizers under one interface.
- `src/train.py` logs both classification metrics and optimization diagnostics.
- `src/evaluate.py` aggregates seed-level metrics into report tables.
- `src/visualize.py` regenerates all report plots.

The code intentionally avoids depending on hidden local state. If the dim-specific embeddings in `data/embeddings/` are missing, `run.py` fails loudly instead of silently falling back to synthetic data.
